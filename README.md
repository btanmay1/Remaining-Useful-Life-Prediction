
# Battery Remaining Useful Life Prediction using Stacked LSTM

This project predicts the Remaining Useful Life (RUL) of lithium-ion batteries using a stacked LSTM neural network.

## Features
- Time-series modeling
- Sequence windowing
- Stacked LSTM architecture
- RMSE and MAE evaluation

## Project Structure
data/ - dataset
models/ - LSTM architecture
preprocessing/ - data preparation
train.py - training script

## Run

pip install -r requirements.txt
python train.py
